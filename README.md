# Altered Domination

A turn-based world-conquest strategy game on a real-world map, with
chess-like board battles. Every country is a player: cities earn income,
income buys units, units move along links between cities and attack their
neighbours. A defended city opens a **board battle** — each unit type moves
and strikes in its own pattern, both sides promote soldiers to generals, and
the battle is won by a *generalmate*: eliminating every enemy general.

- **Platform:** Linux / Windows / macOS desktop (Qt 6.8+, pure QML UI)
- **Engine:** C++23 deterministic core (no Qt) + Qt Quick client · CMake + CPM · doctest
- **Data:** Natural Earth + World Bank, regenerated by one script

This is the 2026 rewrite of the 2018 game; the audit of the old code and the
plan that produced this tree are in
[docs/MODERNIZATION_PLAN.md](docs/MODERNIZATION_PLAN.md).

## Building

Requirements: CMake ≥ 3.27, Ninja, a C++23 compiler (GCC 13+, Clang 17+,
MSVC 19.38+). Qt 6.8+ (Quick, QuickControls2, Svg, Multimedia, ShaderTools)
is needed only for the client — the core and its tests build without Qt.
Dependencies (nlohmann_json, doctest) are fetched automatically via CPM on
first configure.

```bash
# Core + tests only (no Qt needed)
cmake --preset core-debug
cmake --build --preset core-debug
ctest --preset core-debug

# Full desktop build (point QT_ROOT_DIR or CMAKE_PREFIX_PATH at your Qt)
QT_ROOT_DIR=~/Qt/6.8.2/gcc_64 cmake --preset desktop-debug
cmake --build --preset desktop-debug
./build/desktop-debug/client/altereddomination
```

Other presets: `core-asan` (sanitizers), `core-release` (AI benchmarks),
`desktop-release`.

## Playing

Pick a country, a mode (**GDP** — income follows the real economy;
**Equality** — every city earns the same), a difficulty and a seed. Each
round: recruit in your cities, move units along links, attack neighbouring
cities. Undefended cities fall at once; defended ones are fought on the
board. Win by holding 60 % of the world's income.

The full rules are in [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md); the in-game
Codex repeats them with the unit patterns.

## Testing

Every rule in the design docs has doctest coverage:

```bash
ctest --preset core-debug --output-on-failure
./build/core-debug/core/tests/ad-core-tests -tc='battle*'
```

CI runs the suite (plus ASan/UBSan, the data checks and a Qt compile job)
on every push.
