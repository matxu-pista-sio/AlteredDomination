# [Client] Desktop polish: keyboard shortcuts, tooltips, window minimums, high-DPI, headless AD_DRIVE hook and the share-screenshot skill

Labels: enhancement · Type: Feature

## Reported
> this one will only be fore desktop [...] user superpowers plugin

## What happens today
No keyboard navigation beyond `+`/`-` zoom (`mapview.cpp:keyPressEvent`), no tooltips, no high-DPI policy, no minimum window size; there is no way to drive or screenshot the running game without a desktop session.

## Change
- Shortcuts: `E` end turn, `F` find city (search popup), `Escape` close/menu, arrows pan, `+`/`-`/`0` zoom, `Home` capital, `Tab` cycles own cities with unacted units, `R` recruit, `M` move, `A` attack on the selected city; battle: `Enter` ready/end turn, `D` draw, arrows move the cursor, `Space` select.
- Tooltips on every icon button and every unit tile (cost, classes, one-line description).
- `main()`: `Qt::HighDpiScaleFactorRoundingPolicy::PassThrough`, minimum window 1024×640, remembered window geometry.
- `client/src/devdrive.{h,cpp}`: `AD_DRIVE=1` stdin driver (`shot`, `click`, `key`, `type`, `size`, `float`, `quit`) — same contract as TopGen's — so the game can be screenshotted headless (Xvfb + Mesa) in CI and by the assistant.
- `.claude/skills/share-screenshot/SKILL.md` and `.claude/skills/create-ticket/SKILL.md` adapted to this repo; `scripts/ad.py` gains `screenshot <page>`.

## Acceptance criteria
