# [Epic] Online multiplayer: ranked campaigns over a matchmaking + relay server

Labels: enhancement · Type: Feature

## Reported

## What happens today
The legacy tree had a TCP matchmaking client (`multiplayer/multiplayergame.cpp`, port 17777, length-prefixed JSON) for a server that was never in the repository; battles were driven by replaying mouse events. It was removed with #1 and hotseat (GAME_DESIGN.md §7) took its place.

## Decision
Online play is built on TopGen's model - a headless Qt WebSocket server with accounts, ELO, one ranked queue and a setup negotiation - adapted to a turn-based game: **peer lockstep over a relay** (docs/PROTOCOL.md). Both clients run the deterministic core on one seed; the server relays the command log and checks the round hashes. Full shared campaigns, not duel battles.
