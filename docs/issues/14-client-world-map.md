## What happens today
- `MapView : QGraphicsView` draws a `QGraphicsSvgItem` of the 600 KB map, a second SVG mask, and 972 `CityGraphics` items of 800×800 units scaled to 0.09 whose `paint()` draws an ellipse, an SVG, a 60-pt name and the flag (`graphics/citygraphics.cpp:40-85`); zoom is integer steps 1–16 re-scaling every item and rewriting city coordinates.
- Edge-of-screen auto-scroll runs a 120 ms timer translating by 100 px (`mapview.cpp:checkMouseInBoerder`).
- Ownership recolour = SVG rewrite on disk (#3).

## Change
`client/qml/WorldMap.qml` + `components/CityMarker.qml`, `Ocean.qml`, per [docs/UI_THEME.md](https://github.com/matxu-pista-sio/AlteredDomination/blob/claude/dreamy-volta-pvb4kh/docs/UI_THEME.md) "The map stack":
- Territories: `Repeater` over `WorldModel` → `Shape { preferredRendererType: Shape.CurveRenderer; containsMode: Shape.FillContains; ShapePath { fillColor: owner tint; PathSvg { path: territoryPath } } }` with `Behavior on fillColor { ColorAnimation 600 ms }` — a conquest visibly floods the new owner's colour across the territory.
- Borders and links: single `Shape`s (country outlines; land solid / sea dashed / hostile red between different owners).
- City markers: ring by tier, capital star, unit-power badge, name label with zoom LOD, `HoverHandler` + `TapHandler`; flags via `VectorImage`.
- Ocean: `ShaderEffect` (`shaders/ocean.frag`, compiled by `qt_add_shaders`) with slow layered noise and a faint graticule; settings switch to flat colour.
- Camera: `DragHandler`, `WheelHandler`, `PinchHandler` zoom about the cursor (0.4×–8×), keyboard pan/zoom, `flyTo(cityId)` animated, `Home` recentres on the capital; markers scale with `1/sqrt(zoom)`.
- Hover lights the territory outline and name; selection pulses; move targets green, attack targets red.
