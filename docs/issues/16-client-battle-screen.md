## Change
`client/qml/Battle.qml` + `components/UnitChip.qml`, `BoardCell.qml`, `Projectile.qml`, `UnitCard.qml`, `BattleResult.qml`, per [docs/UI_THEME.md](https://github.com/matxu-pista-sio/AlteredDomination/blob/claude/dreamy-volta-pvb4kh/docs/UI_THEME.md) "The battle screen":
- `BattleController` singleton owns the core `Battle`, exposes `BoardModel` (cell → unit id, type, side, general, acted, highlight), phase, side to act, actions left, offers; invokables for every command.
- Board letterboxed to the window, cells as a `Repeater`, chips animated between cells (`Behavior on x/y` 220 ms), strike = `Projectile` along a `PathAnimation` then a `ParticleSystem` burst and the chip's fall; a general's fall shakes the board.
- Deploy: drag or click-swap inside the zone, **Ready**; Promote: click soldiers (crowns), counter of generals left, non-soldier conversion confirmed with a tooltip; Play: select → legal targets from the core (green moves, red strikes), actions-left pips, End turn, Draw offer/accept, Surrender (confirm), Quit (forfeit warning).
- Right-click / long-press a chip → `UnitCard` with the pattern diagram drawn from the catalog (no SVG diagram files).
- AI side: `bestAction` runs via `QtConcurrent::run` at the campaign difficulty budget; each action is animated before the next is requested; the human's input is locked meanwhile.
- Result overlay (won / lost / draw, casualties per type) → back to the campaign with the result applied.
