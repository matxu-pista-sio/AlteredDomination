# [Data] World generator from Natural Earth + World Bank: countries, ~1000 cities, Miller projection, symmetric link graph

Labels: enhancement · Type: Feature

## Reported
> get a new cities and gdp data from better sources and crop them to keep the main cities similarly

## What happens today
- `data/map.json` holds 174 countries and 972 hand-placed cities in millimetres of an Illustrator drawing (`mapview.cpp:214` scales by `2.8346 * zoomLevel`); no lat/lon, no projection, cannot be regenerated.
- 290 of the neighbour links are asymmetric (A lists B, B does not list A) — checked with a script over the file — so movement is one-way on 15 % of links.
- Country names carry typos (`Andora`, `Croatiia`, `Egypte`, `Nambia`, `Uebekistan`, `Venzuela`, `Ivery Coast`, `Mdagascar`, `Equador`, `Lebannon`) and inconsistent case (`morocco`, `philippines`).
- Income is hand-typed (`50` for every Algerian desert town, `20` for every Angolan city); `cityType` disagrees with income; GDP is never read.

## Change
`scripts/gen_world_data.py` (pure Python + Shapely, see [docs/DATA_PIPELINE.md](https://github.com/matxu-pista-sio/AlteredDomination/blob/claude/dreamy-volta-pvb4kh/docs/DATA_PIPELINE.md) §1–§5, §8):
- Sources: Natural Earth 1:50m `admin_0_countries` (polygons, `ISO_A2_EH`, `POP_EST`, `GDP_MD` fallback), 1:10m `populated_places_simple` (lon/lat, `pop_max`, `adm0cap`), World Bank GDP via datasets/gdp (latest year per ISO3), cached under `.cache/raw/`, pinned URLs, `--fetch`.
- Country selection rule (§2): ISO code, `POP_EST ≥ 50 000`, ≥ 1 populated place; ≈ 190 countries, long names.
- Miller projection to a 4096-wide map, lat clipped to [−56°, 84°] (§3).
- City cropping (§4): per-country quota from population + area shares summing to ≈ 1 000, capital first then `pop_max`, 14-map-unit spacing; tiers by population.
- Links (§5): Delaunay (Bowyer–Watson in the script) edges ≤ 140 units + MST edges of the full triangulation; longer edges flagged `sea`; stored once with `a < b`.
- Output `assets/world/world.json` with `version`, `projection`, `sources`, `hash`, deterministic ordering (countries by key, cities by id).
- `scripts/check_world.py`: symmetry, connectivity, no isolated city, unique keys, every country has a capital — run by CI.
