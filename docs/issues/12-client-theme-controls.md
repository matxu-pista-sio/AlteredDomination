# [Client] Theme singleton, from-scratch ADDesktop control style, bundled OFL fonts, settings persistence

Labels: enhancement · Type: Feature

## Reported
> use better UI setup and effects and overall better project design [...] make it wow

## What happens today
- 30 QML files mix `QtQuick.Controls 1.6` and `2.0`, `QtGraphicalEffects` (gone in Qt 6) and hard-coded hex colours in every rectangle (`scripts/MapMenu.qml`, `CityUI.qml`, …); absolute `x/y` pixel layouts sized for one 1200-px-wide window.
- Fonts `Coalition_v2..ttf`, `DESTROY_.ttf`, `District.ttf` of unknown license, loaded by file path in `QFont::setFamily` (`graphics/citygraphics.cpp:82`, which does not even work).
- No settings persist between runs.

## Change
Per [docs/UI_THEME.md](https://github.com/matxu-pista-sio/AlteredDomination/blob/claude/dreamy-volta-pvb4kh/docs/UI_THEME.md):
- `AD.Theme` module: `Style` C++ singleton (`QML_SINGLETON`) with the four roles (ink, paper, brass, lamp), the derived families, the theme-independent map colours, metrics, font families; three themes (`situation-room`, `paper-atlas`, `night-ops`), saved in `QSettings`, applied live, `AD_THEME` env override.
- `ADDesktop` control style over `QtQuick.Templates`: Button, ComboBox, Slider, SpinBox, TextField, CheckBox, ScrollBar, ToolTip, Label, ItemDelegate, Popup, TabButton; picked with `QQuickStyle::setStyle` before the engine loads, Basic as fallback.
- `AD.Components`: `Panel`, `GlassPanel` (MultiEffect blur), `PaperOverlay` (qsb shader), `PageTitle`, `BackButton`, `Toast`, `PipDivider`.
- Fonts: Rajdhani (display) + Source Sans 3 (body), OFL texts bundled; registered in `main()`.
- Settings singleton (`QSettings`-backed) for theme, audio volumes, effects toggles, last-played country.
